# 浏览器凭据威胁模型

Infinite Canvas 采用本地优先模式。浏览器存储中可能包含 AI Provider API Key、WebDAV 凭据、Canvas Agent 地址与连接 Token、模型选择及创作数据。这些值不会被项目托管后端主动保存，但同一浏览器 origin 内执行的脚本可以读取它们。因此该模式适合个人或其他可信浏览器环境，不适合敌对共享设备或不可信插件环境。

## 资产与边界

| 资产 | 存储或路径 | 必须遵守的边界 |
| --- | --- | --- |
| AI Provider API Key 与 WebDAV 凭据 | 浏览器配置存储 | 仅由用户发起的浏览器请求发送给已配置 Provider；不得写入公开 Issue、截图、诊断信息或第三方脚本。 |
| Canvas Agent 地址与连接 Token | 用户显式连接后写入 `localStorage` | 视为本地能力凭据；只能使用可信的本地或 HTTPS endpoint，设备/浏览器配置文件不再可信时应断开连接或清除站点数据。 |
| 一次性 `baseUrl` / `apiKey` URL 参数 | 浏览器启动时读取，随后用 `history.replaceState` 移除 | 参数移除前不得分享链接；长期凭据应优先在“配置”中输入，而非放在链接里。 |
| Canvas Agent 会话身份 | `sessionStorage` | 限定单个浏览器标签页会话，只用于将 Agent 事件和画布工具绑定到该标签页。 |
| Prompt 来源、远程图片、机器生成文本、插件元数据和 Agent 输出 | 外部输入 | 一律按不可信展示数据处理，不能视为可执行指令或凭据。图片 URL 会先归一化，已知不可用的 Prompt 缩略图会在加载前拒绝。 |

## 信任规则

- 第三方节点插件会在当前页面执行，可访问浏览器本地数据（包括 AI API Key）。只能安装和更新来自可信来源的代码；插件不是沙箱。
- Canvas Agent 必须使用显式地址和 Token 连接。客户端只接受 `http:` 或 `https:` endpoint，但协议合法不等于 endpoint 运营者可信。
- FrameFlow 浏览器参考图会先以已验证 PNG 原始字节复制到 Agent 管理的参考资产，再交给 ImageGen；浏览器路径或 URL 本身不能直接成为受控参考资产。
- 浏览器 Prompt、图片 URL、机器生成文本、日志和错误详情均为不可信输入。UI 只能把它们当数据渲染；不得新增 HTML 注入、脚本执行或带凭据的调试输出。
- Agent 日志会遮蔽凭据字段、Data URL，以及常见 Bearer 或赋值式凭据。脱敏只能降低意外暴露，不能让粘贴真实密钥到诊断信息变得安全。

## 已知限制与后续控制

应用仍依赖同源浏览器存储，因此 XSS 或“已信任但恶意”的插件仍可能读取本地凭据。CSP 必须渐进引入：当前应用使用内联主题启动脚本、本地插件、前台直连 Provider 以及用户自定义 endpoint。实施前应先以 report-only 兼容方式记录所需的 script、style、image、connect 和 worker 来源；不得静默阻断用户已配置的 Provider 流量。

发现安全问题时请按[漏洞提交](security.zh-CN)流程，只提交已脱敏证据。
