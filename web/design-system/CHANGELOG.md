# Changelog

## 0.1.3 — 2026-08-11

- Fixed dark semantic CSS aliases so they override the light `:root` values when applications set `data-ds-theme="dark"` or `.ds-theme-dark`.

## 0.1.2 — 2026-07-29

- Updated the documented desktop sidebar pattern from 206 px to 220 px so the complete navigation and brand controls fit without truncation.
- Kept package and DTCG metadata versions aligned for downstream consumers.

## 0.1.1 — 2026-07-29

- Repacked the complete specification and adapter files after the final documentation pass.
- Aligned package and DTCG metadata versions so downstream projects can verify the corrected artifact.

## 0.1.0 — 2026-07-29

- Established primitive, semantic, and component token layers in DTCG 2025.10 format.
- Added framework-independent CSS variables and a Tailwind CSS 4 adapter.
- Added light and dark semantic mappings, Chinese/Latin typography, spacing, elevation, motion, state, and accessibility guidance.
- Added component contracts, adoption checklist, governance rules, and visual QA matrices.
